# Account & Login Access FAQ

_Last updated: 2026-01-15 · Doc ID: FAQ-ACCESS-001_

## I forgot my password

Use the **Forgot password?** link on the sign-in page. A reset link is emailed
to the address on file and is valid for 30 minutes. If it does not arrive,
check spam, then wait 5 minutes before requesting another.

## I'm not receiving the reset email

- Confirm you are using the email address the account was created with.
- Add `no-reply@ourservice.example` to your contacts.
- Corporate mail filters sometimes block the email; try a personal address only
  if it is already on the account.

If the email address on file is no longer accessible, this must be **escalated**
to a human specialist for identity verification. The agent must not change the
email on file.

## My account is locked

Accounts lock after **5 failed sign-in attempts** and unlock automatically after
**30 minutes**. Repeated lockouts should be escalated for a security review.

## Two-factor authentication (2FA) issues

If a customer has lost access to their 2FA device, the agent must **escalate**.
2FA resets require identity verification and cannot be handled automatically.

## What the agent may do

- Walk the customer through the self-service password reset.
- Explain the lockout window.
- Escalate anything requiring identity verification (email change, 2FA reset).
